# غَرْس GHARS
> من هدفٍ تزرعه، إلى إنجازٍ تحصده.

نظام شخصي متكامل لإدارة الأهداف والمهام والتذكير والإنجاز — نسخة الويب (HTML + CSS + JavaScript بدون أي مكتبات خارجية).

---

## التشغيل

الموقع لا يحتاج أي تثبيت. يكفي فتحه عبر خادم محلي بسيط (مُفضّل) أو مباشرة:

- **VS Code:** افتح المجلد ← اضغط بالزر الأيمن على `index.html` ← **Open with Live Server**.
- **أو** افتح `index.html` مباشرة في Chrome / Edge / Firefox.

> البيانات تُحفظ في متصفحك (localStorage) — كل مستخدم له مساحة منفصلة.

### حساب الإدارة الافتراضي
يُنشأ تلقائيًا عند أول تشغيل:

| البريد | كلمة السر |
|---|---|
| `admin@ghars.app` | `Ghars@Admin1` |

غيّر كلمة السر من **الإعدادات ← كلمة السر** بعد أول دخول. (القيم موجودة في `js/core/auth.js` ← `DEFAULT_ADMIN`.)

## أين أعدّل؟

| أريد أن… | الملف |
|---|---|
| أغيّر الألوان أو الخطوط أو أحجام النص | `css/base/variables.css` |
| أضيف لونًا جديدًا للتطبيق | `css/base/variables.css` + `js/core/theme.js` ← `ACCENTS` |
| أعدّل روابط القائمة الجانبية | `js/components/layout.js` ← `NAV` |
| أعدّل شكل صف المهمة | `css/components/task-item.css` + `js/components/task-item.js` |
| أعدّل سلوك المنبّه | `js/services/alarm.js` |
| أضيف نغمة منبّه | `js/services/sounds.js` ← `SOUNDS` |
| أعدّل الرسائل التحفيزية | `js/services/messages.js` |
| أعدّل التصنيفات الجاهزة | `js/services/categories.js` ← `DEFAULTS` |
| أعدّل طريقة حساب النسبة | `js/services/progress.js` |
| أضيف ملف JS جديد | أنشئه ثم أضفه إلى `MODULES` في `js/loader.js` |
| أضيف ملف CSS مشترك | أنشئه ثم أضف `@import` في `css/main.css` |

## القواعد الجوهرية المطبّقة

1. **إيقاف المنبّه ≠ الإنجاز.** المهمة تصبح مكتملة فقط بالضغط على "تم الإنجاز".
2. **كل تنفيذ لمهمة متكررة له سجل مستقل** — لا يُحذف القديم (الأرشيف في "سجل المهمة").
3. **المستثناة والملغاة والمؤجلة لا تُحتسب** في النسبة، وأيام الراحة لا تكسر الـStreak.
4. **عزل البيانات:** كل استعلام مقيّد بالمستخدم الحالي، والإدارة ترى أرقامًا مجمّعة فقط.
5. **كلمات السر مشفّرة** (PBKDF2-SHA256 + ملح عشوائي) ولا تُخزَّن كنص واضح.

## ملاحظات للمرحلة القادمة
- نسخة الويب تحفظ البيانات في المتصفح؛ عند إضافة خادم ومزامنة سحابية يُستبدل `js/core/storage.js` فقط، وتنتقل المصادقة والتشفير إلى الخادم.
- المنبّه في المتصفح يعمل طالما إحدى صفحات غرس مفتوحة؛ المنبّه في الخلفية سيكون ضمن تطبيق Flutter.
